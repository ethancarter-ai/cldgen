# cldgen usage

## Generate markdown

```bash
cldgen generate /path/to/repo
```

## Write to file

```bash
cldgen generate /path/to/repo --output CHANGELOG.md
```

## Start from a tag

```bash
cldgen generate /path/to/repo --since v1.2.0
```

## JSON output

```bash
cldgen generate /path/to/repo --format json
```
